# How this project was made

Lavatune started as a tool Tucker wanted for his own i3 workspace: a small thing in the corner that made sound visible without demanding attention. He set the product direction by using it every day, describing what felt wrong, choosing the motion and color language, and testing each pass in the actual cockpit layout it was built for.

Tucker used OpenAI Codex as a coding agent throughout that process. Codex drafted and revised parts of the Python code, tests, documentation, packaging, and release setup under his direction. This repository does not claim that every line was typed by hand, or that the agent was only an autocomplete tool.

The useful authorship distinction is responsibility. Tucker chose what the program should be, evaluated it on his machines, rejected directions that did not fit, and maintains the code that remains. Codex helped turn those decisions into an implementation and helped audit that implementation before publication.
